Projects

  • User Behviour Driven Interface

    Master’s degree project, developed with a teammate, focused on creating a smart banking web application that learns from individual user behavior and adapts its interface to suggest likely next actions. I built a responsive front end in TypeScript and React, capturing user interactions (clicks, hovers, page transitions) and sending them to a Python/Flask backend for analysis. Using process mining techniques with PM4Py and a Camunda BPMN engine, the system dynamically predicts next steps and identifies unusual user actions. The full stack is containerized with Docker to ensure consistent deployment. This project allowed me to combine web development, data analysis, and process automation in a single application.

    GitHub Repository

  • Process Mining Chrome Extension

    Bachelor’s degree project developed with a teammate, is a Google Chrome browser extension that transforms users’ browsing history into visual workflow models using process mining techniques. I implemented the front end as a Chrome extension, which collects browsing data through the browser API, lets users filter history by date, view usage statistics, download raw data in XES format, and explore visualized process models of their web navigation. The Python backend processes the data into event logs, applies PM4Py to discover workflows, and generates visualizations that can be downloaded or viewed directly in the extension. This project combined browser development, data analysis, and process visualization, giving users structured insights into their browsing behavior.

    GitHub Repository

  • Deep Learning Basics

    This project, developed in a two-person team, focused on designing and training a convolutional neural network (CNN) to classify Polish road signs from images. The model was implemented using Keras, with supporting libraries such as NumPy and Matplotlib, and the codebase was managed through GitHub. During development, we used Weights & Biases for experiment tracking, model checkpointing, and hyperparameter optimization via automated sweeps, allowing us to systematically explore different training configurations.
    The model was trained on publicly available datasets from Kaggle and validated on a manually collected test set of 687 images. Performance was evaluated using accuracy, precision, recall, and F1-score, both overall and per class, providing a detailed understanding of the model’s strengths and limitations.

    GitHub Repository

  • PG IUI NER API

    This project, developed in a five-person team, focused on building an intelligent text-processing service that performs Named Entity Recognition (NER) for both Polish and English. The service exposes a REST API built with FastAPI (Python), enabling users to extract entities (such as people, organizations, and locations) and to fine-tune custom models using their own datasets.
    The system integrates Transformer-based models (RoBERTa) via Hugging Face Transformers and PyTorch, with supporting tools such as Datasets and APScheduler for training orchestration and job scheduling. Two base models — one for Polish and one for English — were provided, with training requests handled through a scalable training queue and progress (e.g., current and total epochs) exposed through the API. Models were trained on CoNLL-2003 and KPWR-NER datasets using roberta-large and polish-roberta-large-v2.

    GitHub Repository
