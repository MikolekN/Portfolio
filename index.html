Banking app that adapts to each user

Master’s thesis with Dawid Łydka, graded 5.0

A simulated banking web app that learns how each user behaves and adapts its interface, from quick shortcuts and menu priorities to a predicted next step.

My part: the Flask backend and MongoDB data model; the event-processing service behind all five adaptive features; a pipeline that mines each user’s event log with PM4Py and deploys it as an executable Camunda 8 process; and about half of the React frontend.
