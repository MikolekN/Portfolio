# Portfolio

Personal site of Mikołaj Nadzieja: https://mikolekn.github.io/Portfolio/

Plain HTML, CSS and a little JavaScript, served by GitHub Pages from `main`.

To preview locally, open `index.html` in a browser, or run `python -m http.server` in this folder and open http://localhost:8000.

The fonts are Atkinson Hyperlegible Next and Atkinson Hyperlegible Mono, hosted in `assets/fonts` under the SIL Open Font License (`assets/fonts/OFL.txt`).
